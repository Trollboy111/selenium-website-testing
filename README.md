# Selenium Website Testing Project

Java Selenium coursework project used to automate and test an e-commerce website.

## Features

- Automated browser testing
- Search functionality tests
- Sorting tests by price and name
- Product filter tests
- Price range validation
- Discount price validation
- Product details validation

## Tech Stack

- Java
- Selenium WebDriver
- JUnit 5
- Maven
- ChromeDriver

## Notes

The tests run against a live website, so they may fail if the website layout, products, prices, or filters change.
